# Ray-Dar
A radar that uses an HC-SR04 ultrasonic sensor and an SG90 servo that spins 15-165 degrees. Logs in centimeters and prints distance on serial monitor. When an object is within 10 centimeters, it will light up a red LED on the breadboard, kind of like a defense system.
